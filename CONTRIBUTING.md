# WorldPECore Contribution Guidelines

Before contributing to WorldPECore, please read this.

## I want to create an issue
* First, use the [Issue Search](https://github.com/MineDg2665/WorldPECore/search?ref=cmdform&type=Issues) to check if anyone has reported it.
* Is your issue related to a Plugin? If so, please contact their original author instead of reporting it here.
* And no, we won't update a Plugin because you need it.
* When reporting, give as much info as you can, and if the Issue is a crash, give the Crash Dump.
* Issues should be written in English or Russian.

## I want to contribute code
* Use the [Pull Request](https://github.com/MineDg2665/WorldPECore/pull/new) system, your request will be checked and discussed.
* __Create a single branch for that pull request__
* If you want to be part of WorldPECore, we will ask you to.
* The code may be unclear and written in English, comments included.


__Thanks for contributing to WorldPECore!__
